# MedChat

A mobile-friendly starter interface for MedChat.

## Files
- `index.html` — page structure
- `style.css` — responsive styling
- `app.js` — local demo message interaction

## Current status
This is a front-end demo only. Messages are displayed in the current browser and are not sent to other users yet. Supabase authentication and real-time messaging can be added next.

## GitHub Pages
In your repository, open **Settings → Pages**, select **Deploy from a branch**, choose the `main` branch and `/ (root)` folder, then save. Wait for GitHub Pages to publish the site.
